# Contributing

Use this repository for Cloudroom GUI issues and changes, not the upstream BB issue tracker.

- Include reproduction steps, expected behavior, actual behavior, and relevant logs. Remove credentials and personal data.
- Keep changes focused. Discuss larger changes before implementing them.
- Follow the [source setup and checks](README.md). Include verification results with your change.
- Preserve upstream copyright and license notices. Never commit credentials, runtime data, or build output.

Development happens in a private monorepo. Public releases are reviewed source snapshots; accepted contributions are brought back into development before the next release.
